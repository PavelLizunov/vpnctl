# Спецификация и Агенто-Читаемая Карта: Crate Inventory

> **Статус аудита:** Завершён сплошной построчный анализ `crates/inventory` (99 файлов, 35 048 строк). Полнота покрытия — 100%.

---

## 1. Архитектурная роль и устройство хранилища

`vpnctl-inventory` — единственный слой персистентности системы.
- **Движок**: `SqliteInventory` поверх `sqlx::SqlitePool` с обязательным включением WAL-режима (`PRAGMA journal_mode = WAL;`), проверкой внешних ключей (`PRAGMA foreign_keys = ON;`), busy-timeout (5000ms).
- **Миграции**: 58 встроенных миграций (`crates/inventory/migrations/`), применяемых автоматически при старте (`sqlx::migrate!("./migrations")`).
- **Нулевой дрифт тестов**: `mem.rs` был полностью удален. Тесты запускаются исключительно на реальном инстансе SQLite во временных каталогах (`tempfile::TempDir`), обеспечивая идентичность логики в тестах и production.
- **Инвариант аудита**: любая мутация состояния (добавление сервера, изменение протокола, выдача гранта, мягкое отключение пользователя, ротация ключей) атомарно записывается в таблицу `audit_log` (`action`, `actor`, `target`, `payload`, `created_at`). Холостые вызовы без реального изменения данных в `audit_log` не пишутся.

## 2. Схема Данных и Ключевые Таблицы

### 2.1 Сущности и Конфигурация
- `servers`: серверы инфраструктуры (`id`, `address`, `ssh_port`, `ssh_user`, `kernels` (JSON array), `enabled_protocols` (JSON array), `trusted_host_fingerprint`, `hoster`, `jump_via`, `usage_coefficient`, `created_at`).
  - Миграция 0053: `role` (primary, backup, egress, transit) для топологии маршрутизации.
- `server_secrets`: таблица секретов серверов (`server_id`, `key`, `value`).
  - Хранит приватные ключи REALITY, PSK для Shadowsocks, соль AmneziaWG, пути к сертификатам TUIC.
  - Каскадное удаление `ON DELETE CASCADE`.
- `users`: пользователи VPN.
  - `id`: уникальное текстовое имя пользователя (например, `alice`, `demonnot-1`, `boosty-11297041`).
  - `uuid`: глобальный VLESS UUID v4.
  - `tuic_password`: секретный пароль для TUIC, Hysteria2, Naive, AnyTLS, Trojan.
  - `wireguard_pubkey`, `wireguard_private`: пара ключей Curve25519 в base64 (44 символа с паддингом `=`).
  - `sub_token`: 43-символьный unpadded URL-safe base64 токен для публичной ссылки подписки `/sub/<token>`.
  - `vpn_router_device_id`: 32-символьный lowercase hex для совместимости с ninitux vpn-router (`/api/v1/app/config/<device_id>`).
  - `disabled`: булев флаг soft-suspend (при `true` ссылка подписки отдает пустой список серверов).
- `grants`: связь пользователей с серверами (`user_id`, `server_id`, `client_uuid`, `granted_at`).
  - `client_uuid`: позволяет переопределить UUID пользователя на конкретном сервере (Phase 1 ninitux merge) без смены глобального UUID.
- `audit_log`: неизменяемый аудит-лог административных и фоновых действий (`id`, `actor`, `action`, `target`, `payload`, `created_at`).

### 2.2 Мониторинг, Качество, Сессии и Биллинг
- `node_health`: телеметрия состояния узлов (сэмплы CPU, RAM, диска, uptime, сетевого трафика NIC bytes, количества рестартов демонов `nrestarts`).
- `server_quality_samples` / `service_quality`: метрики доступности, RTT, потерь пакетов и jitter для протоколов на узлах. Алгоритм `score_samples` вычисляет объективный рейтинг качества.
- `vpn_stats_hourly` / `vpn_user_daily` / `vpn_user_source_ips`: агрегация переданных байт, сессий и уникальных IP-адресов подключения.
  - **Фильтрация шума**: встроенный список `OUR_EGRESS_CONTROL_IPS` (например, `83.97.108.34`) исключает служебные запросы самого шлюза и мониторинга из статистики активности реальных клиентов.
- `server_billing` & `server_payments` (миграции 0057, 0058):
  - Модуль учета стоимости серверов, циклов оплаты (Monthly, Quarterly, SemiAnnual, Annual), мультивалютности (RUB, USD, EUR, KZT) и курсов валют (`currency_rates`).
- `boosty_settings` & `boosty_subscribers`:
  - Настройки интеграции Boosty (токены, интервалы опроса, авто-дизейбл, grace period).
  - `acquire_boosty_sync_lease`: распределенная аренда (lease lock) в БД для исключения параллельной работы воркеров.

## 3. Декомпозиция Подмодулей `crates/inventory/src/`

- **`sqlite/users/`**:
  - `crud.rs`: создание, редактирование, удаление пользователей, установка soft-suspend (`set_user_disabled`).
  - `grants.rs`: выдача и отзыв доступов пользователей к серверам, управление per-server UUID.
  - `keys.rs`: валидация и безопасная ротация ключей WireGuard, UUID и паролей.
  - `lifecycle.rs`: отслеживание времени создания, активности и отключения учетных записей.
- **`sqlite/servers/`**:
  - `crud.rs`: регистрация серверов, смена портов, адресов, хостеров.
  - `protocols.rs`: включение и выключение протоколов на серверах с предварительной валидацией через `Registry`.
  - `deploy.rs`: сохранение состояния деплоя, статусов демонов и истории накатки конфигов.
  - `billing.rs` / `currency.rs`: учет тарифов хостинга, дат продления VPS и конвертация курсов.
  - `role.rs`: управление топологическими ролями узлов.
- **`sqlite/access/`**:
  - `logging.rs`: аудит и запись каждого события доступа к `/sub/` и `/api/v1/app/config/` с фиксацией IP, User-Agent, ASN и страны.
  - `analytics.rs`: выявление совместного использования подписок (account sharing detection), подозрительной одновременной активности с разных географических локаций.
  - `bans.rs`: блокировка скомпрометированных токенов и подозрительных IP.
- **`sqlite/stats/`**:
  - `ingest.rs`: прием сырых счетчиков байт от демонов через SSH probe.
  - `rollups.rs`: почасовая и посуточная агрегация трафика.
  - `limits.rs`: учет квот трафика с учетом множителя `usage_coefficient`.
- **`backup/`**:
  - Модуль горячего резервного копирования без остановки сервиса (`sqlite3_backup` API).
  - `snapshot.rs`: создание gzip/zstd снапшотов с проверкой контрольных сумм SHA-256.
  - `verify.rs`: глубокая проверка целостности бэкапа (`PRAGMA integrity_check;`, сверка количества таблиц и миграций).
  - `restore.rs`: безопасное атомарное восстановление из бэкапа с проверкой версии миграций (запрет отката на несовместимую старую схему без подтверждения).
  - `retention.rs`: правила ротации старых снапшотов.
- **`migrate/`**:
  - Парсинг legacy-конфигураций из старых bash-скриптов (`parse_bash_inventory_env`, `parse_bash_singbox`) и генерация чистого плана миграции в SQLite.
- **`jump_resolver.rs`**:
  - Рекурсивный резолвер цепочек ProxyJump: проверяет отсутствие циклов и валидирует закрепленные отпечатки для всех промежуточных бастионов.
