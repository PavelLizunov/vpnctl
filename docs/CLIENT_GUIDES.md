# Руководство по подключению к VPN для пользователей

Это подробная инструкция по настройке подключения на всех платформах: **iOS (iPhone/iPad)**, **Android**, **Windows**, **macOS**, **Linux** и **Android TV**.

Поддерживаются современные протоколы с защитой от блокировок (VLESS Reality, Hysteria2, TUIC, WireGuard / AmneziaWG).

---

## 🚀 Быстрый старт (самое главное)

Вам обычно выдается **один из двух вариантов**:
1. **Ссылка на подписку (URL)** вида `https://.../api/v1/sub/...` или `http://.../sub/...` — **самый удобный способ**. По ней приложение автоматически загружает и обновляет все доступные серверы и страны.
2. **QR-код** — тот же URL подписки или отдельный ключ, который можно отсканировать прямо в приложении.

Ниже выберите ваше устройство и следуйте простой пошаговой инструкции.

---

## 📱 1. iOS (iPhone / iPad)

### Вариант 1 (Рекомендуемый): Happ Proxy Utility
> **Happ** — очень удобное, быстрое и современное приложение на базе ядра sing-box. Отлично работает со ссылками подписки и QR-кодами, поддерживает все новейшие протоколы.

1. **Установите приложение:**
   * Скачайте из App Store: **Happ Proxy Utility** (или найдите в поиске «Happ»).
2. **Добавление подписки по ссылке (URL):**
   * Скопируйте выданную вам ссылку подписки в буфер обмена.
   * Откройте **Happ**.
   * Приложение обычно само предложит добавить ссылку из буфера обмена. Если нет — нажмите значок **`+`** в правом верхнем углу.
   * Выберите **«Добавить из буфера»** (или **«Add from Clipboard»** / **«Добавить подписку»**).
   * Вставьте ссылку и сохраните.
3. **Если у вас QR-код:**
   * Нажмите **`+`** в правом верхнем углу → выберите **«Сканировать QR-код»** (Scan QR).
   * Наведите камеру на QR-код (или выберите фото/скриншот с QR-кодом из галереи).
4. **Подключение:**
   * В списке выберите желаемую локацию/сервер (например, `Germany`, `Netherlands` и т.д.).
   * Нажмите большую кнопку подключения (тумблер по центру).
   * При первом включении iOS попросит разрешение: **«Разрешить добавление конфигураций VPN»** → нажмите **«Разрешить»** и введите код-пароль от iPhone.

---

### Вариант 2: V2rayTun
> Простой, стабильный и полностью бесплатный клиент в App Store.

1. Скачайте в App Store: **V2rayTun**.
2. Скопируйте ссылку подписки или подготовьте QR-код.
3. Откройте **V2rayTun**:
   * Для ссылки: нажмите **`+`** вверху → выберите **«Импорт подписки»** (Import from clipboard / Add subscription) → вставьте ссылку → нажмите **Сохранить/Обновить**.
   * Для QR-кода: нажмите **`+`** → **«Сканировать QR-код»** (Scan QR code).
4. Выберите нужный сервер в списке и нажмите круглую кнопку подключения внизу экрана.
5. Подтвердите системный запрос iOS на добавление VPN-профиля.

---

### Альтернативы для iOS:
* **Streisand** (бесплатно в App Store) — аналогично: `+` → добавить подписку.
* **Shadowrocket** (платное ~$3) — эталонное приложение для iOS: автоматически подхватывает ссылку из буфера при открытии.
* **AmneziaVPN** (если вам выдан файл `.conf` или ссылка `vpn://` для AmneziaWG):
  * Скачайте **Amnezia VPN** в App Store.
  * Нажмите «У меня есть данные для подключения» → «Вставить ключ или файл» → вставьте текст/ссылку или выберите `.conf`.

## 🤖 2. Android (смартфоны и планшеты)

### Вариант 1 (Рекомендуемый): v2rayNG
> Самый проверенный, надёжный и популярный клиент для Android.

1. **Установите приложение:**
   * Скачайте из **Google Play**: поиск **v2rayNG** (разработчик *2dust*).
   * Либо из **RuStore** или **GitHub Releases**.
2. **Добавление подписки по ссылке (URL):**
   * Скопируйте вашу ссылку подписки.
   * Откройте **v2rayNG**.
   * Откройте боковое меню (три полоски слева вверху) → выберите **«Группы подписок»** (Subscription group setting).
   * Нажмите значок **`+`** в правом верхнем углу.
   * В поле «Имя группы» напишите любое название (например, `Мой VPN`).
   * В поле **«URL-адрес подписки»** вставьте вашу ссылку.
   * Нажмите галочку в правом верхнем углу, чтобы сохранить.
   * Вернитесь на главный экран. Нажмите меню (три точки справа вверху) → **«Обновить подписку»** (Update subscription).
   * Появится список доступных серверов.
3. **Если у вас QR-код:**
   * На главном экране v2rayNG нажмите **`+`** в правом верхнем углу → **«Сканировать QR-код»** (Scan QR code) либо **«Импорт QR-кода из галереи»**.
4. **Подключение:**
   * Нажмите на нужный сервер в списке (справа появится зеленая полоска выбора).
   * Нажмите круглую кнопку подключения с буквой **`V`** в правом нижнем углу.
   * При первом запуске разрешите Android создание VPN-подключения (нажмите **«ОК»**).

---

### Вариант 2: Happ или Hiddify
> Очень красивый и простой интерфейс, отлично подходит тем, кто не хочет разбираться в меню.

1. Скачайте **Happ** или **Hiddify** из Google Play / RuStore.
2. Скопируйте ссылку подписки.
3. Откройте приложение:
   * Нажмите кнопку добавления профиля (значок `+` или «Новый профиль»).
   * Выберите **«Добавить из буфера обмена»** (Add from clipboard).
4. Список серверов загрузится автоматически.
5. Нажмите большую круглую кнопку подключения по центру.

## 💻 3. Windows (ПК и ноутбуки)

### Вариант 1 (Рекомендуемый): Hiddify
> Идеально для Windows: стильный интерфейс, один клик для подключения, встроенная поддержка TUN-режима (перенаправляет весь трафик системы).

1. **Скачайте и установите:**
   * Скачайте установщик с официального сайта или GitHub (`Hiddify-Windows-Setup.exe`).
   * Установите и запустите от имени администратора.
2. **Добавление подписки:**
   * Скопируйте вашу ссылку на подписку.
   * Откройте **Hiddify**.
   * Нажмите значок **`+`** (или «Новый профиль» / «Добавить из буфера обмена»). Ссылка добавится автоматически.
3. **Подключение:**
   * Выберите сервер/страну из списка.
   * Убедитесь, что включен переключатель **«VPN / Режим TUN»** (чтобы трафик всех браузеров и программ шёл через VPN).
   * Нажмите большую кнопку подключения по центру.

---

### Вариант 2: Mihomo Party / Clash Verge Rev
> Отличные клиенты с поддержкой формата Mihomo (Clash Meta), который используется в нашей системе по умолчанию.

1. Скачайте и установите **Mihomo Party** или **Clash Verge Rev** (для Windows x64).
2. Перейдите в раздел **«Profiles»** (Профили / Подписки).
3. В поле ввода вставьте вашу ссылку подписки и нажмите **«Download» / «Импорт»**.
4. Выберите загруженный профиль (сделайте его активным).
5. Включите переключатель **«System Proxy»** (Системный прокси) или **«Tun Mode»** (Туннельный режим) для перенаправления всего трафика.

---

### Вариант 3: v2rayN
> Классический мощный клиент для Windows.

1. Скачайте архив **v2rayN-With-Core.zip** из официального GitHub Releases, распакуйте в любую папку и запустите `v2rayN.exe`.
2. Скопируйте ссылку подписки.
3. В верхнем меню нажмите **«Подписка»** (Subscription Group) → **«Настройка подписок»** → нажмите **«Добавить»** → вставьте URL в поле `Url` → сохраните.
4. Снова нажмите меню **«Подписка»** → **«Обновить подписку без прокси»**.
5. Выберите сервер, нажмите `Enter` (или правой кнопкой мыши → «Сделать активным сервером»).
6. Внизу окна переключите режим на **«Автоматическая настройка системного прокси»** (Clear system proxy → Set system proxy) либо включите галочку **«Режим TUN»**.

### Вариант 1 (Самый простой): Hiddify или V2rayTun

2. Скопируйте ссылку на подписку.

1. Скачайте сборку `.dmg` (для Apple Silicon M1/M2/M3/M4 выберите `arm64`, для старых Mac на Intel — `x64`).

3. Активируйте профиль, перейдите в настройки и включите **Tun Mode** (Туннельный режим) для перенаправления трафика всей системы.

## 🐧 5. Linux (Ubuntu, Debian, Fedora, Arch и др.)

### Вариант с графическим интерфейсом (GUI):
* Скачайте **Hiddify** (AppImage / .deb) или **Mihomo Party** (AppImage).
* Сделайте AppImage исполняемым: `chmod +x app.AppImage` и запустите.
* Вставьте URL подписки в разделе профилей, включите **TUN Mode** и подключитесь.

### Вариант без GUI (Консоль / Сервер):
1. Используйте ядро **Mihomo** или **sing-box**:
   * Скачайте готовый конфиг по вашей ссылке:
     ```bash
     curl -fsSL "ВАША_ССЫЛКА_ПОДПИСКИ?format=mihomo" -o /etc/mihomo/config.yaml
     # или если нужен формат sing-box:
     curl -fsSL "ВАША_ССЫЛКА_ПОДПИСКИ?format=sing-box" -o /etc/sing-box/config.json
     ```
2. Запустите демон через systemd:
   ```bash
   sudo systemctl enable --now mihomo
   # или
   sudo systemctl enable --now sing-box
   ```

## 📺 6. Android TV / Смарт ТВ

1. Установите на ТВ приложение **v2rayNG** или **Hiddify**:
   * Их можно найти в Android TV Google Play Store, либо перенести файл `.apk` через флешку / приложение *Send Files to TV*.

   * Нажмите `+` → введите/вставьте URL подписки.
   * Нажмите «Обновить подписку».
   * Выберите сервер и нажмите «Подключиться».

## ❓ Частые вопросы и решение проблем (FAQ)

### 1. Как обновить список серверов (если добавился новый сервер или изменился адрес)?
* В **Happ / Hiddify**: проведите пальцем сверху вниз по списку серверов для обновления или нажмите значок стрелочек обновления рядом с подпиской.
* В **v2rayNG**: откройте меню (три точки) → нажмите **«Обновить подписку»**.
* В **v2rayN / Mihomo**: нажмите правой кнопкой на профиль → **«Update»** (Обновить).
* *Рекомендуется обновлять подписку раз в 1–2 недели или если перестал работать какой-то сервер.*

### 2. Подключение включено, но интернет не работает:
* **Проверьте выбор сервера:** переключитесь на другую страну (например, с Германии на Нидерланды или Финляндию).
* **Проверьте режим TUN:** на ПК (Windows/macOS) убедитесь, что в приложении включен **«TUN Mode»** или системный прокси. Без этого трафик приложений не пойдёт в туннель.
* **Проверьте время на устройстве:** в настройках устройства время и дата должны стоять автоматически (рассинхронизация более чем на 60 секунд блокирует шифрование TLS/Reality).
* **Смените протокол/порт:** если провайдер жестко глушит один протокол, переключитесь в списке на сервер с другим протоколом (например, с VLESS на Hysteria2 или AmneziaWG).

### 3. Что делать, если выдан файл `.conf` (WireGuard / AmneziaWG)?
* Установите приложение **AmneziaWG** или **AmneziaVPN**.
* Нажмите кнопку **«Добавить туннель / Добавить подключение»** → выберите **«Импорт из файла»** → укажите ваш файл `.conf`.
* Нажмите тумблер включения.
